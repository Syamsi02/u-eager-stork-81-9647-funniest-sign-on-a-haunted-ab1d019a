A one-line sign for a haunted server room door: the resident ghost closes tickets as "works on my machine" — so knock twice before entering. A small Python program writes the sign to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```

This writes the sign (one line, under 120 characters) to `./output/entry.txt`.
